Vera

An offline memory prototype exploring whether local language models can retrieve and correct stored information without inventing details.

Built

A local Python memory engine using SQLite/FTS5, Ollama, and source-grounded retrieval.

Evaluated

Attribution, corrections, conflicting records, controlled writes, and multi-turn responses.

Observed

Some fluent model responses introduced unsupported information, requiring stricter evaluation and verification.

How it works

  1. Store with provenanceKeep retrievable records and their source information separate from model-generated responses.
  2. Retrieve and answerUse source-backed context to answer questions without silently changing records.
  3. Evaluate failuresCompare responses to known records and measure unsupported details and omissions.

Status & limitations

Independent prototype and evaluation work. No claim of production readiness or use with real family records.
