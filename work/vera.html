Offline AI and memory

Vera

An offline AI memory prototype exploring how a conversational system can remember what someone actually said without making up the rest.

The idea

Imagine telling a device a story about a family trip. Months later, you ask about it. A useful memory system should find the original account, answer from that information, and make it clear when something wasn't recorded. If the story is corrected later, the system should handle that correction rather than quietly mixing the two versions together.

That sounds straightforward, but language models are good at producing plausible sentences even when the facts are missing or incomplete.

What I built

Developed a local memory engine in Python using SQLite with full-text search, Ollama, and a local language model. The stored records remain the source of truth. The model retrieves relevant information and uses it to answer questions; it isn't allowed to silently rewrite those records.

The prototype tracks where information came from, handles proposed corrections, and requires controlled steps before new memories are written. Because it runs locally, the underlying design does not require sending the memory archive to a cloud model.

What I learned

Built test conversations with known facts and compared the answers to the original records. Some responses sounded natural but added unsupported details, changed meanings, or left out relevant information. Those failures shaped the evaluation process and the rules around memory updates.

Vera remains a research prototype. The experiments help identify what still needs improvement before a system like this could be trusted with real family stories.
