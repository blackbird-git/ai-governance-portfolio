AI Security Engineering Lab

A local test environment for evaluating security controls around AI applications and tool use.

Built

A local lab using Python, FastAPI, Ollama, synthetic financial records, and Wazuh.

Tested

Unauthorized tool and data requests, prompt injection scenarios, and application enforcement of access boundaries.

Documented

Reproducible tests, observed authorization results, security events, and known limitations.

How it works

  1. Define the boundaryIdentify what the application must authorize before invoking tools or returning data.
  2. Run controlled testsSend permitted and unauthorized requests against synthetic records.
  3. Inspect evidenceCheck API responses, test results, and Wazuh monitoring events.

Status & limitations

Independent lab testing does not establish security in a production deployment. Results apply to the specific controlled cases tested.
