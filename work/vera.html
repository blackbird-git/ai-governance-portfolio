Vera: Local AI Memory Engine

Developed Vera as an offline memory prototype and used it to test whether local AI models can retrieve attributed records, track corrections, and answer questions without inventing details.

Background

Designed Vera around a common failure: a language model can sound certain while confusing sources or adding unsupported details. Kept the source archive authoritative and tested how the application handles retrieval, conflicting information, and proposed memory changes.

Approach

Attributed records

Store text records in local SQLite with source metadata, full text search, and correction history.

Grounded retrieval

Retrieve and select evidence before asking a local model to compose a response, then validate references.

Controlled writes

Require explicit confirmation before a proposed by the model memory becomes part of the archive.

Honest evaluation

Compare models and response strategies using synthetic datasets, holdouts, regression tests, and documented quality limitations.

Contribution: Defined the product boundaries, directed implementation with acceptance criteria, designed evaluation cases and holdouts, reviewed model behavior, and rejected approaches that introduced unsupported facts.

Results and evidence

The public repository records 122 automated regression tests. Vera uses local SQLite storage and Ollama inference. The evaluation results are based on controlled synthetic datasets.

Model comparisons exposed a recurring tradeoff: more natural answers sometimes added details unsupported by the source. A planning experiment improved compliance with topic exclusions without improving answer completeness. Those failures informed decisions about what not to promote into the main engine.

Evaluation numbers are based on small synthetic datasets, with some judgments reviewed by an agent. They are useful within the experiment but should not be treated as general model benchmarks.

Limitations

  • Conversational recall and answer completeness remain inconsistent.
  • The local archive is not encrypted, and there is no multiple user authorization layer.
  • The system does not process audio or images, despite the future family memory concept.
  • Experimental model comparisons have not established a production quality replacement for the reference model.

Lessons

Evaluations showed that more natural responses sometimes introduced facts absent from the source. Adjusted the testing approach to measure unsupported details and omissions rather than treating fluent answers as successful.
